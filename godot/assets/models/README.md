# Dinosaur and environment models

This folder contains all 3D assets generated by `tools/blender_assets.py`. Run `blender --background --python tools/blender_assets.py` to regenerate everything.

## Asset list

### Dinosaurs (5 species)
- `dino_{id}_skin.glb` – skinned mesh with PBR material.
- `dino_{id}_rig.glb` – armature + mesh with animation clips `idle`, `walk`, `eat`, `roar`.
- `dino_{id}_skin_preview.png`, `dino_{id}_rig_preview.png` – preview renders.

Species ids: `trex`, `raptor`, `triceratops`, `stego`, `brachio`.

### Tools (6)
Model ids match the `tools` entries in `godot/data/catalog.json` exactly.
- `tool_shovel.glb`
- `tool_pickaxe.glb`
- `tool_trowel.glb`
- `tool_brush.glb`
- `tool_spray.glb`
- `tool_chisel.glb`
- `tool_{id}_preview.png`

### Excavation layers (3 biomes × 3 layers)
- `soil_{biome}_layer{N}.glb` where biome is `desert`, `forest`, `ice` and N is 1–3.
- `soil_{biome}_layer{N}_preview.png`

### Museum modules
- `museum_pedestal.glb`
- `museum_case.glb`
- `museum_sign.glb`
- `museum_{module}_preview.png`

### HUD atlas
- `../ui/hud_atlas.png` – 512×512 atlas.
- `../ui/hud_atlas.glb` – plane with the atlas material.
- `../ui/hud_atlas_preview.png`

## Naming rules
- Dinosaur: `dino_{id}_{skin|rig}.glb`
- Tool: `tool_{id}.glb` where `id` is the catalog tool id (`shovel`, `pickaxe`, `trowel`, `brush`, `spray`, `chisel`)
- Soil: `soil_{biome}_layer{N}.glb`
- Museum: `museum_{module}.glb`
- Preview: same base name + `_preview.png`

## Godot import settings
- **Meshes**: Import as scene, enable `Generate Collision` (or add `-col` suffix to collision meshes). Use `PBR Material` from glTF.
- **Animations**: Import as `AnimationPlayer` clips. The rig files contain NLA tracks named `idle`, `walk`, `eat`, `roar`.
- **Materials**: Principled BSDF exports to glTF PBR (metallic/roughness). No custom shaders.
- **Scale**: 1 Blender unit = 1 Godot meter. Models are Y-up after glTF export.
- **Collision**: For excavation layers and museum modules, add simple box collision in Godot or use `-col` suffix meshes if generated.
