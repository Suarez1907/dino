# Asset licenses

The dinosaurs are original meshes made for this project. The terrain colors and the sky are CC0 photographs and an HDRI from Poly Haven. No other third-party meshes are shipped.

Quaternius’s Animated Dinosaur Pack (CC0) was considered. The public Google Drive copy was over its download quota, the pack is FBX rather than glTF, and it has Apatosaurus and Parasaurolophus instead of Brachiosaurus. It also has no eat or roar clip. The game therefore uses the original rigs below.

## Original dinosaurs

Generated by `web/scripts/export_dinos.mjs` from `web/src/dino_rig.js`. The same builder draws the web prototype. Godot loads the exported glTF files in `godot/assets/models/`.

| File | What it is | License |
| --- | --- | --- |
| `godot/assets/models/triceratops.glb` | Living Triceratops, skinned, idle / walk / eat / roar, plus a low mesh | CC0. Original work in this repository. |
| `godot/assets/models/velociraptor.glb` | Living Velociraptor, same clips | CC0. Original work in this repository. |
| `godot/assets/models/stegosaurus.glb` | Living Stegosaurus, same clips | CC0. Original work in this repository. |
| `godot/assets/models/trex.glb` | Living T-Rex, same clips | CC0. Original work in this repository. |
| `godot/assets/models/brachiosaurus.glb` | Living Brachiosaurus, same clips | CC0. Original work in this repository. |
| `godot/assets/models/*_skeleton.glb` | Museum bones for that species, named `skull__`, `torso__`, `tail__`, `leg_l__`, `leg_r__`, and `frill__` / `plates__` / `neck__` / `arm__` when that species has them | CC0. Original work in this repository. |

Each living model is a few thousand triangles. The Low graphics setting builds the same rig with fewer segments. Teeth are short and rounded. Eyes are large. Nothing is gory. The pieces are parented to the bones, so idle, walk, eat, and roar move the head, jaw, legs, and tail.

Regenerate the glTF files from `web/` with `node scripts/export_dinos.mjs`.

## Poly Haven terrain and sky

Poly Haven assets are CC0. Authors and files:

| File in `godot/assets/textures/` | Poly Haven asset | Maps | Author |
| --- | --- | --- | --- |
| `sand.jpg` | [aerial_sand](https://polyhaven.com/a/aerial_sand) | Diffuse, 1k JPG | Rob Tuytel |
| `sand_n.jpg` | [aerial_sand](https://polyhaven.com/a/aerial_sand) | Normal (GL), 1k JPG | Rob Tuytel |
| `grass.jpg` | [forest_floor](https://polyhaven.com/a/forest_floor) | Diffuse, 1k JPG | Dimitrios Savva |
| `rock.jpg` | [rocky_terrain_02](https://polyhaven.com/a/rocky_terrain_02) | Diffuse, 1k JPG | Rob Tuytel |
| `snow.jpg` | [snow_02](https://polyhaven.com/a/snow_02) | Diffuse, 1k JPG | Rob Tuytel |
| `sky.hdr` | [kloofendal_48d_partly_cloudy_puresky](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky) | HDRI, 1k | Greg Zaal |

The ground shader blends sand, grass, rock, and snow from height, slope, and biome. Dig holes drop the heightmap so the pit floor reads as darker soil and the walls read as rock. `sand_n.jpg` is the matching normal map kept beside the diffuse; the runtime blend uses the diffuse maps plus roughness from slope.

Downloaded from `https://dl.polyhaven.org` on 14 November 2026. Poly Haven’s license page: https://polyhaven.com/license
